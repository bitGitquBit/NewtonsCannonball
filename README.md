# NewtonsCannonball
Coding up a Newton's Cannonball simulation using Matplotlib

Matplotlib needs to be installed 

Newton's Cannonball is a thought experiment that says: if you throw a cannonball above the surface of the Earth with enough speed, the curvature of the Earth will cause it to come back at the starting position.

Experiment by changing h and u (Height of cannonball above surface and initial speed) All units are SI units
